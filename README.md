# Cobblemon Shuffled

Aims to fairly rebalance older and weaker pokemon to either fit a strong competitive niche better or better usability in casual battles.

The following principles guide the balance changes made:

- Preserving a Pokemon's battle style if possible
- Improving Pokemon that fall just short of being effective at what they're designed to do.
- Only nerfing Pokemon who stand miles above the rest

## Installation

1. Download the release compatible with your Cobblemon installation.
2. Place the ZIP file into your world's datapacks folder.
3. Place the ZIP file into your resourcepack folder and enable it.
4. Load or reload your world.
5. Verify that the datapack is enabled. Command `/datapack list`

## Balance Documentation

Files are included for each pokemon generation. Documenting changes made to a Pokemon.

- Base stat changes: Increases, decreases.
- Ability changes: New abilities, replacements, and custom ability additions.
- Move pool changes: Additions or adjustments to a Pokémon's available moves.

## Documentation Format

Each Pokémon is listed in National Pokédex order.

Example: generation4-balance-changes.md

```md

    ## 407_Roserade

    - Base Stats:
      - Speed: 90 => 101
    - Moves:
      - Tm: Follow me

```

## Feedback

Suggestions and feedback are welcome. The aim is to make more Pokémon worth using while retaining the qualities that make each Pokémon unique/(uniquely bad).
